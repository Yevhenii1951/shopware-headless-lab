# Brief: Shopware 6 Headless + Next.js (учебный проект)

## Цель
Научиться работать с Shopware 6 в headless-режиме: понять устройство платформы, подключиться через Store API, построить собственный фронт на Next.js (App Router) и закрепить подход Spec Driven Development + TDD.

## Контекст
Мы не переписываем и не модифицируем ядро Shopware. Наша задача — научиться правильно настраивать платформу (Sales Channel, каталог) и строить вокруг неё собственное приложение.

## Ограничения
- Не трогаем `vendor/`, `src/Core/`. Правки только в админке, либо в `custom/plugins/` строго по необходимости
- Тестируем ТОЛЬКО наш код (хелперы, маппинг данных Store API, логика корзины, утилиты). Ядро Shopware не покрываем тестами
- Минимум тестов там, где проверяем конфигурацию платформы (лучше чек-лист)
- Меньше "на будущее", больше минимального вертикального среза
- Фокус на обучении: объяснять "что", "зачем", "чему учимся" перед каждым действием

## Подход
- **SDD**: спека -> требования -> acceptance-критерии -> код
- **TDD**: Red -> Green -> Refactor. Применяем к `apps/storefront-next/`
- **Headless**: отдельный API Sales Channel в Shopware. Аутентификация через `sw-access-key` заголовок
- **Монорепозиторий**: `apps/`, `docs/sdd/`, `tools/`, `packages/`

## Первый вертикальный срез
Цель первого среза максимально узкая:

1. Получить список **категорий** через Store API и вывести на главной странице Next.js
2. Получить список **товаров** выбранной категории (или общий список) через Store API и вывести в виде карточек

Только это. Никакой корзины, никакого чекаута, пока не отработаем связку "конфиг Sales Channel -> Store API -> наш фронт" и не напишем под это тесты.

## Нефункциональные требования
- TypeScript строгий, без `any`
- Понятная структура, без излишних абстракций
- Явные типы под минимально нужные поля ответов Store API
- Переменные окружения только через `.env.example` + локальный `.env.local`
- Коммиты осознанные, без "WIP на всё подряд"

## Критерий готовности первого среза
- В админке создан отдельный **API Sales Channel** под headless, скопирован `sw-access-key`
- В Next.js есть минимальный клиент для Store API
- Главная страница выводит категории и товары из Shopware
- Есть фейлинг-тест -> реализация -> зелёный под наш хелпер работы с Store API
- Спека (`requirements.md`, `acceptance.md`) ведётся параллельно с реализацией
