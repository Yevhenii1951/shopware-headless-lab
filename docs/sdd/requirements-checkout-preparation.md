# Requirements: Checkout preparation

## Цель
Изучить доступные способы доставки и оплаты в Store API context, затем позволить выбрать способ оплаты до создания заказа.

## Функциональные требования

### FR-1. Методы checkout
- FR-1.1. Получить доступные способы доставки через `POST /shipping-method?onlyAvailable=1`.
- FR-1.2. Получить доступные способы оплаты через `POST /payment-method?onlyAvailable=1`.
- FR-1.3. Вывести название каждого доступного метода на `/cart`.

### FR-2. Выбор оплаты
- FR-2.1. Добавить `selectPaymentMethod(paymentMethodId)`.
- FR-2.2. Передавать выбранный ID через `PATCH /context` с `paymentMethodId`.
- FR-2.3. На `/cart` есть форма выбора способа оплаты.

## Исключения
- Не создаём заказ, не собираем адрес, не интегрируем оплату.
- Способ доставки в этом slice только показывается: payload его смены не реализуем без подтверждённого контракта.
