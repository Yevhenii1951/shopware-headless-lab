# Requirements: Первый вертикальный срез (категории + товары)

## Контекст
Первый срез максимально узкий. Цель — отработать связку "API Sales Channel -> Store API -> Next.js фронт" и закрепить TDD под наш код.

## Функциональные требования

### FR-1. Настройка Shopware под headless
- FR-1.1. В админке должен быть создан отдельный **API Sales Channel** под headless
- FR-1.2. У Sales Channel должен быть скопирован **API access key** (`sw-access-key`)
- FR-1.3. Sales Channel должен иметь доступ к нужным языку/валюте (минимум de-DE/EUR либо те, что есть в демо-окружении)

### FR-2. Store API клиент (наш код)
- FR-2.1. Создать минимальный клиент `apps/storefront-next/src/lib/shopware/client.ts` для запросов к Store API
- FR-2.2. Клиент должен использовать заголовок `sw-access-key`
- FR-2.3. Базовый URL берётся из переменной окружения `NEXT_PUBLIC_SHOPWARE_STORE_API_URL` (или эквивалент)
- FR-2.4. Клиент должен быть простым, без излишних абстракций

### FR-3. Получение категорий
- FR-3.1. Реализовать хелпер для получения категорий через Store API
- FR-3.2. Вывести список категорий на главной странице Next.js
- FR-3.3. Типы под ответ Store API должны быть явными и минимальными (только нужные поля)

### FR-4. Получение товаров
- FR-4.1. Получить список товаров (минимум через endpoint категорий/товаров Store API)
- FR-4.2. Вывести карточки товаров на главной странице
- FR-4.3. Отобразить минимально необходимую инфу: название, цена (базовая), ссылка/идентификатор

## Нефункциональные требования

- NFR-1. **Только наш код тестируем**. Тесты пишем в `apps/storefront-next/` под хелперы/клиент/маппинг
- NFR-2. TypeScript строгий, без `any`
- NFR-3. Явные типы, минимум полей
- NFR-4. Переменные окружения в `.env.example`, реальные в `.env.local` (не коммитим)
- NFR-5. Не трогаем ядро Shopware (`vendor/`, `src/Core/`)
- NFR-6. Объясняем перед каждым действием

## Исключения (явно не делаем в этом срезе)
- Корзина
- Оформление заказа (checkout)
- Фильтры/поиск
- Детальная страница товара (может появиться позже, но не требуется для критерия готовности)
- Админка/плагины
