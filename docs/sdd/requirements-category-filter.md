# Requirements: Фильтр товаров по категории

## Цель
Отработать передачу выбранной категории из Next.js в Store API criteria и получить соответствующий список товаров.

## Функциональные требования

### FR-1. Запрос к Store API
- FR-1.1. `getProducts` принимает необязательный `categoryId`.
- FR-1.2. Без `categoryId` хелпер получает общий список товаров.
- FR-1.3. С `categoryId` хелпер передаёт Store API filter `equals` по `categories.id`.

### FR-2. URL и UI
- FR-2.1. Каждая категория на главной — ссылка с `?categoryId=<id>`.
- FR-2.2. Ссылка «Все товары» сбрасывает фильтр.
- FR-2.3. На странице видно название выбранной категории.

## Ограничения
- Тестируем только свой helper и его запрос к Store API.
- Не меняем Shopware core, каталог или данные демо-окружения.
- Не добавляем поиск, пагинацию или вложенные категории в этот slice.
