# Requirements: Корзина (cart)

## Цель
Отработать работу с корзиной через Store API: создать/получить корзину, добавить товар, посмотреть содержимое корзины.

## Функциональные требования

### FR-1. Хелперы под cart
- FR-1.1. Создать `getCart()` — получить текущую корзину
- FR-1.2. Create/createOrGet корзину, либо просто добавить в корзину используя `POST /store-api/checkout/cart/line-item`
- FR-1.3. Добавить `addToCart(productId, quantity)`
- FR-1.4. Использовать тот же `shopwareFetch` с `sw-access-key`

### FR-2. Маршрут
- FR-2.1. Страница `/cart` — просмотр корзины
- FR-2.2. Кнопка "Добавить в корзину" на детальной странице товара

### FR-3. Вывод
- FR-3.1. Список позиций в корзине
- FR-3.2. Количество, название, цена
- FR-3.2. Сумма (минимально)

### FR-4. Удаление из корзины
- FR-4.1. Добавить `removeFromCart(lineItemId)` 
- FR-4.2. Использовать `DELETE /store-api/checkout/cart/line-item/{id}`
- FR-4.3. Кнопка "Удалить" на странице `/cart`
