# Acceptance Criteria: Первый вертикальный срез

## AC-1. Shopware подготовлен
- [ ] Создан отдельный **API Sales Channel** под headless
- [ ] Скопирован `sw-access-key`
- [ ] Есть доступ к админке демо-окружения и видно категории/товары

## AC-2. Next.js проект готов к TDD
- [ ] Проект `apps/storefront-next/` инициализирован (Next.js App Router, TypeScript)
- [ ] Настроен тестовый раннер (Vitest/Jest — выберем и объясним почему)
- [ ] Есть базовая структура `src/lib/shopware/`, `src/app/`

## AC-3. TDD цикл отработан
- [ ] Написан **красный** тест под хелпер получения категорий (тест фейлит, функции нет)
- [ ] Реализован минимальный клиент + хелпер, тест **зелёный**
- [ ] Проведён минимальный рефактор без "заготовок на будущее"

## AC-4. Интеграция с Store API
- [ ] Клиент использует `sw-access-key` в заголовке
- [ ] Конфиг через `.env.local` (есть `.env.example`)
- [ ] Запрос к Store API работает из Next.js

## AC-5. UI результата
- [ ] На главной странице (`/`) отображается список **категорий** из Shopware
- [ ] На главной странице отображаются **карточки товаров** (минимум название + цена)
- [ ] Данные приходят реально из поднятого Shopware (не захардкожены)

## AC-6. Документация/процесс
- [ ] В процессе объяснял "что/зачем/чему учимся" перед каждым действием
- [ ] Спека соответствует реализации (минимальный срез)
- [ ] Коммиты осознанные
