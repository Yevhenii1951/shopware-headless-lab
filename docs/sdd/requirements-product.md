# Requirements: Детальная страница товара

## Цель
Добавить минимальный переход с главной на детальную страницу товара. Отработать связку "получить товар по id" через Store API и отобразить минимальную информацию.

## Функциональные требования

### FR-1. Хелпер получения товара по ID
- FR-1.1. Создать `getProductById(id: string)` в `apps/storefront-next/src/lib/shopware/products.ts` (либо отдельный файл)
- FR-1.2. Использовать тот же минимальный `shopwareFetch` с заголовком `sw-access-key`
- FR-1.3. Маппить ответ Store API в минимальный тип `{ id, name, price, description? }`

### FR-2. Маршрут
- FR-2.1. Создать динамический маршрут `app/product/[id]/page.tsx`
- FR-2.2. Страница должна быть серверным компонентом (async)
- FR-2.3. Получать `id` из `params`

### FR-3. Вывод
- FR-3.1. Отобразить название, цена
- FR-3.2. При наличии — краткое описание
- FR-3.2. Ссылка "Назад на главную"

## Нефункциональные требования
- NFR-1. Только наш код тестируем (TDD под `getProductById`)
- NFR-2. TypeScript строгий, без `any`
- NFR-3. Минимальная реализация, без излишних абстракций
- NFR-2. Не трогаем ядро Shopware
